# Support for DataRealm Humanoid Application Lab

Thank you for using and exploring software from **DataRealm Humanoid Application Lab** (`HumanoidAppLab`). We want to make sure you have the resources and support you need to build, test, and deploy with our tools.

---

## Getting Help

Before opening an issue or contacting maintainers, please review the resources below.

### 1. Documentation & Website

- **Official Website**: [HumanoidAppLab.com](https://HumanoidAppLab.com)
- **Repository Documentation**: Check each project's `README.md`, `docs/` folder, and wiki (if enabled).

### 2. Frequently Asked Questions & Discussions

If you have questions about how to use an API, integrate hardware, or explore architectural ideas:
- **GitHub Discussions**: Check the **Discussions** tab on the specific repository or organization page (if enabled). Search past discussions for answers to common questions.
- **Search Issues**: Check both open and closed issues on the repository to see if a similar question or topic has already been addressed.

### 3. Reporting Bugs and Issues

If you encountered unexpected behavior or errors:
- Use the **Bug Report** template when opening an issue in the relevant repository.
- Provide a minimal reproducible example, reproduction steps, and system environment info.

### 4. Direct Inquiries & Partnerships

For organizational inquiries, research collaborations, commercial applications, or industrial deployment partnerships:
- Visit [HumanoidAppLab.com](https://HumanoidAppLab.com)
- Reach out to leadership and maintainers at: [info@DataRealmInc.com](mailto:info@DataRealmInc.com)
